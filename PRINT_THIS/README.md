# Print these files

This folder contains only the current S01 version.

| File | Contents |
|---|---|
| [S01_complete_kit_PETG_P2S.3mf](S01_complete_kit_PETG_P2S.3mf) | Two panel plates, eight PETG mounts and one flat PETG jig |
| [S01_panel_PLA_P2S.3mf](S01_panel_PLA_P2S.3mf) | The same panel, with PLA settings |
| [S01_panel.stl](S01_panel.stl) | Panel geometry for your own slicing |
| [S01_wall_mount_2p2.stl](S01_wall_mount_2p2.stl) | Wall mount with the selected 2.2 mm pilot |
| [S01_alignment_jig_5p2.stl](S01_alignment_jig_5p2.stl) | Flat jig with 5.2 × 15.2 × 4.4 mm locators |

Native projects target P2S / 0.4 mm, 0.2 mm layers, four walls and 100% infill. No supports. Choose the PETG or PLA panel as needed; mounts and jig use PETG. Keep scale at 100%.

The 5.2 mm PETG strip fit was selected after printing. The deeper jig and selected 2.2 mm screw pilot are the next full-size assembly test.
