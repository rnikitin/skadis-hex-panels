# Archived experiments

`experiments/` preserves earlier generator/validation source and numerical reports. These files record the design history; they are superseded by the current package.

The original sibling-directory layout is retained where historical scripts import one another. Some scripts write generated files next to their source. Use the current CLI for active development.

Earlier human-language reports have been replaced by the English summaries in [design history](../docs/history.md) and [analysis](../analysis/v3/README.md). Raw solver field arrays, duplicate archives, scratch environments and machine-local logs are excluded from version control; they can be regenerated from the retained inputs and solver.

Archived STL files are not compatible with the current hidden-joint receivers unless explicitly stated. The initial S01/S02/S06 and small rear-key experiments remain useful comparison material.
